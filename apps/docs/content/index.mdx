# A Turborepo remote cache you host yourself

Every laptop and CI runner on your team shares build outputs through storage you own. Deploy the server to Cloudflare Workers with one button, or build it for Node.js, Vercel, AWS Lambda, and other platforms.

[Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https://github.com/AdiRishi/turborepo-remote-cache-cloudflare) [Read the docs](/introduction)

</HomeHero>

## Why host your own cache

- **No Vercel account.** `turbo` talks to your server through the official Remote Cache API, and you choose where your artifacts live.
- **Free to start.** The Workers free plan includes 100,000 requests a day, and R2 includes 10 GB of storage a month. R2 charges nothing for egress, so cache downloads have no R2 bandwidth charge. See [Cloudflare pricing](https://developers.cloudflare.com/r2/pricing/) for storage and operations.
- **Your choice of storage.** Keep artifacts in R2, Workers KV, any S3-compatible bucket, or anything with a [Files SDK](https://files-sdk.dev) adapter.
- **See what you save.** The [dashboard](/dashboard) shows cache hits, time saved, and which teams and CI runners use the server.
- **Signed artifacts.** The server stores each artifact's signature and returns it unchanged, so `turbo` can reject anything it didn't sign.

## Set it up

<Steps>
    <Step title="Deploy the Worker">
        The [Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https://github.com/AdiRishi/turborepo-remote-cache-cloudflare) button copies this repository to your GitHub or GitLab account and deploys it with an R2 bucket. You can also [deploy with Wrangler](/deploy/cloudflare#build-and-deploy).
    </Step>
    <Step title="Set a token">
        Generate a long random token and add it to the Worker as a secret named `TURBO_TOKEN`.

        ```sh
        openssl rand -hex 32
        ```
    </Step>
    <Step title="Point turbo at the Worker">
        Give your application repository the server's URL, token, and a team name:

        ```sh
        export TURBO_API='https://turborepo-remote-cache.<your-subdomain>.workers.dev'
        export TURBO_TOKEN='replace-with-your-token'
        export TURBO_TEAM=my-team
        ```
    </Step>

</Steps>

[Get started](/get-started) takes you through your first remote cache hit. Then [connect your team and CI](/connect-turbo) so they can reuse those builds too.
