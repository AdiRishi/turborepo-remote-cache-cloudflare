# Self-hosted remote cache for Turborepo

Share build outputs across CI, teammates, and coding agents without a Vercel account or egress fees. Deploy to Cloudflare Workers and R2 in one click, or bring your own runtime and S3 bucket.

## Why self-host

- **Drop-in v8 API** Implements the official Turborepo Remote Cache specification natively. Set `remoteCache.apiUrl` in `turbo.json` and export `TURBO_TOKEN`. No Vercel account or `turbo login` required.
- **Zero egress on Cloudflare R2** Cloudflare's free tier covers 100,000 Workers requests a day and 10 GB of R2 storage. Because R2 charges nothing for egress, heavy CI downloads never run up bandwidth bills.
- **End-to-end artifact signing** Stores and returns `x-artifact-tag` headers untouched so `turbo` verifies HMAC-SHA256 signatures locally. Your signing key never leaves your machines.
- **Portable runtime and storage** Built on [Nitro](https://nitro.build) and [Files SDK](https://files-sdk.dev). Run on Cloudflare Workers, Node.js, Bun, Deno, Vercel, Netlify, or AWS Lambda with R2, KV, S3, or a custom adapter.

## Up and running in minutes

<Steps>
    <Step title="Deploy the server">
        Use the [Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https://github.com/AdiRishi/turborepo-remote-cache) button to fork this repository and provision a Worker, an R2 bucket, and a D1 stats database automatically. Prefer the CLI? Follow the [Cloudflare Workers guide](/deploy/cloudflare).
    </Step>
    <Step title="Generate a bearer token">
        Create a 32-byte secret and add it to your Worker as `TURBO_TOKEN`:

        ```sh
        openssl rand -hex 32
        ```
    </Step>
    <Step title="Point turbo at your deployment">
        Commit `remoteCache` in your root `turbo.json` and export `TURBO_TOKEN` on developer machines and in CI:

        ```json turbo.json
        {
            "remoteCache": {
                "apiUrl": "https://turborepo-remote-cache.<your-subdomain>.workers.dev",
                "teamSlug": "my-team"
            }
        }
        ```
    </Step>
    <Step title="Enable artifact signing">
        Recommended for any shared cache. Set `"signature": true` in `turbo.json` and share `TURBO_REMOTE_CACHE_SIGNATURE_KEY` across trusted machines so `turbo` rejects unsigned or tampered artifacts.
    </Step>

</Steps>

Follow the [Quickstart](/get-started) for a full walkthrough, [Connect Turborepo](/connect-turbo) for CI setup, or [Artifact signing](/sign-artifacts) to configure HMAC verification.
