## Deploy the Worker

If your Cloudflare account has never used R2, turn it on under **R2 Object Storage** in the [Cloudflare dashboard](https://dash.cloudflare.com/) first. Then press the button:

<a href="https://deploy.workers.cloudflare.com/?url=https://github.com/AdiRishi/turborepo-remote-cache-cloudflare">
    <img
        src="https://deploy.workers.cloudflare.com/button"
        alt="Deploy to Cloudflare"
        width="184"
        height="39"
    />
</a>

Sign in, connect GitHub or GitLab, and keep the build and deploy commands Cloudflare fills in. The first deploy creates the Worker, an R2 bucket for artifacts, and a D1 database for the dashboard. Copy the Worker's URL when it's done.

## Set the token

Generate a token:

```sh
openssl rand -hex 32
```

In the Worker's **Settings** > **Variables and Secrets**, add it as a secret named `TURBO_TOKEN`. Anyone with this token can read and write your cache, so treat it like a password.

<a id="run-your-first-remote-hit" />

## Point turbo at it

In your Turborepo repository, add the Worker's URL to the root `turbo.json`:

```json turbo.json
{
    "remoteCache": {
        "apiUrl": "https://turborepo-remote-cache.<your-subdomain>.workers.dev",
        "teamSlug": "my-team"
    }
}
```

Then give your shell the token:

```sh
export TURBO_TOKEN='<your token>'
```
