This guide takes you from zero to a working remote cache on Cloudflare Workers with R2 storage and D1 analytics. You'll need a Cloudflare account, a GitHub or GitLab account, and a Turborepo repository.

Prefer deploying via the Wrangler CLI? See [Cloudflare Workers](/deploy/cloudflare). Deploying elsewhere? Start with [Platforms](/deploy).

<Steps>
    <Step title="Enable R2 and deploy the Worker">
        If you haven't used R2 on your Cloudflare account yet, open **R2 Object Storage** in the [Cloudflare dashboard](https://dash.cloudflare.com/) and activate it first (10 GB/month is free).

        Then deploy the server:

        <a href="https://deploy.workers.cloudflare.com/?url=https://github.com/AdiRishi/turborepo-remote-cache">
            <img
                src="https://deploy.workers.cloudflare.com/button"
                alt="Deploy to Cloudflare"
                width="184"
                height="39"
            />
        </a>

        Sign in, connect GitHub or GitLab, and keep the pre-filled build and deploy commands (`pnpm run build` and `pnpm run deploy`). The first deployment provisions the Worker, an R2 bucket (`turborepo-cache`), and a D1 database (`turborepo-cache-stats`) for the dashboard. Copy the resulting `*.workers.dev` URL once the deploy finishes.
    </Step>
    <Step title="Set TURBO_TOKEN">
        Generate a random bearer token:

        ```sh
        openssl rand -hex 32
        ```

        In your Worker's **Settings** > **Variables and Secrets**, add a secret named `TURBO_TOKEN` with that value. Treat it like a password: anyone holding it can read and write artifacts across all teams on this deployment.
    </Step>
    <Step title="Point Turborepo at your Worker">
        Add the Worker's origin (no trailing slash, no `/v8`) and a team slug to your repository's root `turbo.json`:

        ```json turbo.json
        {
            "remoteCache": {
                "apiUrl": "https://turborepo-remote-cache.<your-subdomain>.workers.dev",
                "teamSlug": "my-team"
            }
        }
        ```

        Export the token in your shell:

        ```sh
        export TURBO_TOKEN='<your-token>'
        ```
    </Step>
    <Step title="Verify your first remote hit">
        <include>/_snippets/verify-remote-cache.mdx</include>
    </Step>

</Steps>
