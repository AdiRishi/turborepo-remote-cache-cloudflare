This project is an open-source remote cache server. Deploy it to Cloudflare Workers with one button, or run it on AWS Lambda, Vercel, Netlify, Node.js, Bun, or Deno. Then add a few lines to `turbo.json` to point `turbo` at it.

<CacheFlow />

## Stop building the same thing twice

- **CI rebuilds only what changed.** A pull request rebuilds the packages it changed and the ones that depend on them. Everything else replays from the cache.
- **A fresh clone skips its first build.** A new teammate, a new laptop, or a throwaway worktree downloads its builds instead of making them.
- **Coding agents rerun less.** An agent that runs the test suite fifty times an afternoon replays every task whose inputs it didn't touch.

## Know the trade-offs

<a id="one-token-opens-every-team" />

- **One token opens every team.** Anyone with the token reads and writes every team's artifacts. If two groups must stay apart, give each its own deployment.
- **Your copy doesn't update itself.** The button copies this repository into your account. To get a new release, [merge it into your copy](/update).
- **The dashboard is public until you restrict it.** Anyone with the URL sees your team names and usage. [Restrict access](/dashboard#restrict-access) before you share it.
- **Serverless hosts cap artifact size.** Vercel, Netlify, and AWS Lambda accept about 5 MB per upload. Cloudflare Workers accepts 100 MB or more. [Compare platforms](/deploy#artifact-size-limits) before you pick one.
