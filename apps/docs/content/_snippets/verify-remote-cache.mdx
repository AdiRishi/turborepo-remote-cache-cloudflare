Run a cacheable task twice, with the local cache disabled for both runs. These examples use the `turbo` installed in your project through pnpm:

```sh
pnpm exec turbo run build --cache=remote:rw
pnpm exec turbo run build --cache=remote:r --summarize
```

The first run builds and uploads any missing artifacts. The second reads only from the server. For tasks with unchanged inputs and caching enabled, expect `cache hit, replaying logs` on the second run.

`Remote caching enabled` confirms configuration, but does not prove a hit. The JSON summary in `.turbo/runs/` records `"remote": true` and `"status": "HIT"` in each task's `cache` field when the server supplied its artifact.

If a task still misses, use [Troubleshooting](/troubleshooting#builds-keep-missing). Once verified, run builds normally to use both the local and remote caches.
