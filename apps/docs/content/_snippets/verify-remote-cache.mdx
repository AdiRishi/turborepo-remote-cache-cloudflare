`turbo` only uploads artifacts for tasks it executes; local cache hits stay local. To verify the full upload and download round-trip, clear `.turbo/cache` and run a build to populate the remote cache:

```sh
rm -rf .turbo/cache
npm exec -- turbo run build
```

Now clear `.turbo/cache` a second time to simulate a fresh machine and run the build again:

```sh
rm -rf .turbo/cache
npm exec -- turbo run build
```

You should see remote caching active and every task replaying from the server:

```text
   • Remote caching enabled

build: cache hit, replaying logs edf677b2880f0799

  Tasks:    1 successful, 1 total
 Cached:    1 cached, 1 total
   Time:    19ms >>> FULL TURBO
```

Because `.turbo/cache` was empty before the second run, every cache hit came from your remote server. If tasks still miss, check [Builds keep missing](/troubleshooting#builds-keep-missing).
