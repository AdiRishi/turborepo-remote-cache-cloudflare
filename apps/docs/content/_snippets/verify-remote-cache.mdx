Run a cacheable task twice with the local cache switched off. No global `turbo`? Swap in `pnpm exec turbo` or `npx turbo`:

```sh
turbo run build --cache=remote:rw
turbo run build --cache=remote:r --summarize
```

The first run builds anything the server doesn't have yet and uploads it. The second run can read from the server and nothing else, so every hit it reports came from your server. Look for these lines:

```text
   • Remote caching enabled

build: cache hit, replaying logs edf677b2880f0799

  Tasks:    1 successful, 1 total
 Cached:    1 cached, 1 total
   Time:    19ms >>> FULL TURBO
```

`FULL TURBO` means every task came back from the cache. `Remote caching enabled` on its own only means `turbo` found a URL, a token, and a team. It doesn't mean anything hit.

`--summarize` writes a JSON summary to `.turbo/runs/`. A task restored from the server has this `cache` field:

```json
{ "local": false, "remote": true, "status": "HIT", "source": "REMOTE", "timeSaved": 118 }
```

If tasks still miss, see [Builds keep missing](/troubleshooting#builds-keep-missing). Once it works, drop the `--cache` flag. `turbo` then checks the local cache first and your server second.
