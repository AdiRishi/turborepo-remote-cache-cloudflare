:::warning[< 6 MB payload limit]
AWS Lambda caps synchronous invocation payloads at 6 MB, and Base64 encoding plus the event envelope shrink usable artifact size further. Review [Artifact size limits](/deploy#artifact-size-limits) before choosing Lambda for large monorepos.
:::

## Build the Lambda bundle

Requires Node.js 24+ and the pnpm version in `package.json`. Clone your fork, run `pnpm install --frozen-lockfile` from the repository root, and check the `turbo.json` warning in [Build from source](/deploy#build-from-source).

Build the Lambda output from the repository root:

```sh
NITRO_PRESET=aws_lambda pnpm build
```

Then deploy the bundle:

1. Package the contents of `apps/api/.output/server` as your Lambda deployment archive.
2. Select a Node.js runtime and set the handler to `index.handler`.
3. Expose the function over HTTPS via a Lambda Function URL or an API Gateway HTTP API.

## Configure environment and IAM permissions

Set the token and bucket details on the Lambda function:

```sh
TURBO_TOKEN=<your-token>
S3_BUCKET=my-turborepo-cache
S3_ENDPOINT=https://s3.us-east-1.amazonaws.com
```

Leave `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, and `S3_REGION` unset to authenticate with the function's IAM execution role. Lambda populates `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, and `AWS_REGION` automatically, and the server falls back to all four.

Grant the execution role these permissions on your bucket:

- `s3:GetObject`
- `s3:PutObject`
- `s3:DeleteObject`
- `s3:ListBucket`

## Verify and enable stats

Follow [Connect Turborepo](/connect-turbo) with your HTTPS endpoint to verify remote hits. Because Lambda's filesystem is ephemeral, [configure a hosted stats database](/stats-database) if you want dashboard history.

## Scheduled expiry

The Lambda preset does not wire up EventBridge schedules automatically. Trigger `POST /internal/delete-expired-objects` daily from EventBridge Scheduler, GitHub Actions, or any HTTP cron. See [Run expiry from a scheduler](/retention#run-expiry-from-a-scheduler).
