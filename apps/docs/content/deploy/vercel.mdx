:::warning[4.5 MB payload limit]
Vercel Functions cap HTTP request and response bodies at 4.5 MB. Larger build artifacts fail to upload and will never hit the remote cache. Check your typical artifact sizes before deploying on Vercel (see [Artifact size limits](/deploy#artifact-size-limits)).
:::

## Create the project

Start from your fork of this repository (review [Build from source](/deploy#build-from-source) first):

<Steps>
    <Step title="Import into Vercel">
        Import your fork in the Vercel dashboard and set **Root Directory** to `apps/api`. Keep **Include source files outside of the Root Directory in the Build Step** enabled, since the API imports workspace packages from `packages/`.
    </Step>
    <Step title="Set the build command">
        Set **Build Command** to:

        ```sh
        pnpm exec turbo run build
        ```

        Running from `apps/api` builds the [dashboard](/dashboard) first, then compiles the API. Nitro auto-detects Vercel and selects the `vercel` preset (you can also set `NITRO_PRESET=vercel` explicitly).
    </Step>
    <Step title="Add environment variables and deploy">
        | Variable | Purpose |
        | --- | --- |
        | `TURBO_TOKEN` | Bearer token shared with `turbo` clients. |
        | `S3_BUCKET`, `S3_ENDPOINT`, `S3_REGION`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | Artifact storage. See [S3-compatible storage](/storage/s3). |
        | `CRON_SECRET` | Random secret Vercel attaches to scheduled cron calls; requests without it are rejected. |
    </Step>

</Steps>

## Use the production URL

Point `remoteCache.apiUrl` at your project's **production** URL (such as `https://<project>.vercel.app`), not a preview URL. Vercel Deployment Protection gates preview deployments behind a login screen that `turbo` cannot pass.

Follow [Connect Turborepo](/connect-turbo) to verify remote hits. Because Vercel's filesystem is read-only, [configure a hosted stats database](/stats-database) if you want dashboard history.

## Scheduled expiry

The Vercel build automatically registers a Vercel Cron Job at `/_vercel/cron` scheduled for `0 3 * * *` (03:00 UTC; on the Hobby plan, Vercel triggers it within the 03:00–03:59 UTC window).

Always set `CRON_SECRET`; without it, the `/_vercel/cron` endpoint can be invoked publicly.
