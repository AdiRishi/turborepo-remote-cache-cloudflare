On Cloudflare Workers, configuration comes from Worker bindings, `vars`, and secrets. On all other platforms, it comes from `process.env`. Values are validated per request; invalid or missing required settings return `500` and log `Invalid server configuration: <reason>`.

## Core variables

| Variable                         | Required | Default | Description                                                                                                      |
| -------------------------------- | -------- | ------- | ---------------------------------------------------------------------------------------------------------------- |
| `TURBO_TOKEN`                    | Yes      | —       | Non-empty bearer token required on `/v8/*` and `/internal/*` (compared in constant time via SHA-256).            |
| `BUCKET_OBJECT_EXPIRATION_HOURS` | No       | `720`   | Artifact retention in whole hours (`>= 1`). Also sets KV write-time TTL. See [Retention and expiry](/retention). |

## Cloudflare bindings

Available only on Cloudflare Workers (`apps/api/wrangler.jsonc`):

| Binding    | Resource     | Description                                                          |
| ---------- | ------------ | -------------------------------------------------------------------- |
| `KV_STORE` | KV namespace | Stores artifacts in [Workers KV](/storage/kv). Overrides `R2_STORE`. |
| `R2_STORE` | R2 bucket    | Stores artifacts in [Cloudflare R2](/storage/r2) (default).          |
| `STATS_DB` | D1 database  | Stores analytics for the [dashboard](/dashboard). Optional.          |

## S3 variables

Setting `S3_BUCKET` enables [S3-compatible storage](/storage/s3) when no custom adapter and no Cloudflare storage binding (`KV_STORE` / `R2_STORE`) is configured.

| Variable               | Required    | Default                                                   | Description                                                                                |
| ---------------------- | ----------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `S3_BUCKET`            | Yes, for S3 | —                                                         | Non-empty bucket name.                                                                     |
| `S3_ENDPOINT`          | Yes, for S3 | —                                                         | S3 API endpoint URL (e.g. `https://s3.us-east-1.amazonaws.com`). Only the origin is used.  |
| `S3_REGION`            | No          | `AWS_REGION`, then `AWS_DEFAULT_REGION`, then `us-east-1` | Signing region. Set `auto` for Cloudflare R2.                                              |
| `S3_ACCESS_KEY_ID`     | No          | `AWS_ACCESS_KEY_ID`                                       | Access key ID.                                                                             |
| `S3_SECRET_ACCESS_KEY` | No          | `AWS_SECRET_ACCESS_KEY`                                   | Secret access key.                                                                         |
| `S3_SESSION_TOKEN`     | No          | `AWS_SESSION_TOKEN` (when using `AWS_*` keys)             | Temporary session token for IAM roles.                                                     |
| `S3_FORCE_PATH_STYLE`  | No          | `false`                                                   | Set `true` to address `<endpoint>/<bucket>` instead of `<bucket>.<endpoint>` (e.g. MinIO). |

`AWS_*` fallbacks are read strictly from the process environment; `~/.aws` profiles and SSO sessions are not loaded.

## Build and platform variables

| Variable       | Scope                  | Description                                                                                                            |
| -------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `NITRO_PRESET` | Build                  | Nitro deployment target (e.g. `node_server`, `aws_lambda`). Defaults to `cloudflare_module`. See [Platforms](/deploy). |
| `PORT`         | Node.js, Bun, and Deno | HTTP listening port. Defaults to `3000`.                                                                               |
| `HOST`         | Node.js, Bun, and Deno | Network interface / host address to bind.                                                                              |
| `CRON_SECRET`  | Vercel                 | Bearer secret verified on Vercel Cron requests to `/_vercel/cron`. See [Vercel](/deploy/vercel).                       |

A [custom storage adapter](/storage/custom-adapter) can read any additional variables you define.

## HTTP endpoints

| Endpoint                                | Auth         | Description                                                                                  |
| --------------------------------------- | ------------ | -------------------------------------------------------------------------------------------- |
| `GET /`                                 | None         | Serves the [analytics dashboard](/dashboard).                                                |
| `GET /stats`                            | None         | Returns dashboard analytics as JSON ([`/stats` details](/dashboard#read-the-stats-as-json)). |
| `GET /ping`                             | None         | Returns `pong` for uptime and load-balancer health checks.                                   |
| `/v8/artifacts/...`                     | Bearer token | Official Turborepo Remote Cache v8 API. See the [API reference](/api).                       |
| `POST /internal/delete-expired-objects` | Bearer token | Runs artifact expiry on demand ([details](/retention#run-expiry-on-demand)).                 |

CORS headers on `/v8/*` allow browser requests from any origin. Error responses return JSON in the form `{"code":"unauthorized","message":"Missing or invalid bearer token"}`.
